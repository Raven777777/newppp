## 使用约定

1. **归属**：新任务必须落在「连通 / 生命周期 / 可维护」三者之一，否则进 Backlog。
2. **触发条件**：Backlog 条目必须写清"观察到什么现象才启动"，没有触发条件的需求直接拒绝（防止 QUIC 指纹混淆这类项悄悄插队）。
3. **验收即完成**：每项的完成标准是一条能跑的命令或一个具名测试，不写形容词。
4. **顺序**：P0 → P1 → P2 → P3，P4 穿插做；Backlog 不占带宽，只有触发条件命中才启动。

- [x] **P0-1 启动期配置告警**
  - 做法：`--listen` 给了非全零 IP → WARN"IP 部分被忽略，总是绑定全部接口"；`--bind 0.0.0.0`/`--http-bind 0.0.0.0` 且无 `--inbound-auth` → WARN。
  - 验收：e2e T9/T10 断言日志。
  - 债：D6

- [x] **P0-2 错误分类短语化**
  - 做法：`OpenError` 带固定分类词 `dial-failed` / `session-limit` / `bad-target` / `private-target-denied`；SOCKS5 映射 RFC1928 回复码，HTTP 代理回 `502` + `X-Newppp-Error`。
  - 验收：e2e T3/T5/T6 断言错误码与文本。

- [x] **P0-3 `too many gaps` 报错附提示**
  - 做法：`quic_tune::gap_hint` 在连接死亡/结束时自动追加"弱网建议 `--recv-window 1..2`"。
  - 验收：`wt connection dead` / 服务端 `wt conn ended` 日志可 grep 到。
  - 债：D5

- [x] **P0-4 CA bundle 时效提醒**
  - 做法：`build_docker.py` 使用缓存时检查 mtime 超过 90 天输出提醒。
  - 验收：改 mtime 跑一次可见。

- [x] **P0-5 协议版本显式协商**
  - 做法：AUTH 载荷首字节 `proto_version`；服务端返回具名 `VersionMismatch` 并 ERROR 日志，不匹配不消耗 nonce。
  - 验收：`auth_version_mismatch_is_explicit` / `auth_matching_version_succeeds`（cargo test）。

- [x] **P0-6 未认证连接数上限**
  - 做法：`UnauthGate` 全局 `--max-unauth`（默认 128）+ 每源 IP 1/8；WT 直连按 IP、降级仅全局。
  - 验收：`unauth_gate_*` 单元测试；认证后名额立即释放，不影响已认证并发。
  - 债：D1

### P1 端到端测试 + CI（1~2 周，最高优先，是后续一切的安全网）— ✅ 已完成

利用 `src/lib.rs` 在进程内起 server + client，不依赖外部 curl。全部落在 `tests/e2e.rs`（真实监听器 + 真实 Outbound/入站 + 原始 socket 客户端断言）：

1. [x] fallback POST：SOCKS5 → TCP 目标 200（`fallback_post_socks5_and_http_connect`，同测 HTTP 代理 CONNECT / absolute GET）
2. [x] fallback WS：同上走 wss 路径（`fallback_ws_socks5_get`）
3. [x] HTTP 代理入站 CONNECT（含在 `fallback_post_socks5_and_http_connect` 中）
4. [x] SOCKS5 CONNECT + UDP ASSOCIATE（回环 echo server，`socks5_connect_and_udp_associate_over_wt`）
5. [x] 超 MTU UDP 数据报自动落流（`udp_over_mtu_falls_back_to_stream`，8KB：> QUIC datagram 上限、≤ 16KB 帧上限，双向断言完整）
6. [x] 认证矩阵：bearer 错误→伪装页、AUTH 帧错误、nonce 重放拒绝、错钥 AUTH 帧无声断开（`auth_matrix`）
7. [x] 私网默认拒绝（SOCKS 0x02 + HTTP 502 `X-Newppp-Error`）；`--allow-private-targets` 放行；拨号失败 0x05（`private_target_policy`）

## 明确的"不做"（写下来防止以后摇摆）

- **不加 Alt-Svc**：UDP 443 现在不应答网页请求，广播 Alt-Svc 等于邀请浏览器来探测一个答不上话的端口。即使将来做了 h3 共宿也不加——暴露面只增不减。
- **不做多级 fallback**：WT→POST/WS 已覆盖全部三种部署形态，POST 再挂时节点大概率整个不可达。
- **不做 per-user ACL/配额/计费**：`--auth` 多用户 + 连接级限速对"少量可信用户"够用。
- **不做自适应调参**（recv-window/conns 自动调优）：替代动作是把调参经验写进 [运维手册.md](运维手册.md)（见 P4-2/P4-3）。
- **不拆 crate/微服务**：目录边界已清楚，`lib.rs` 已支撑集成测试。
